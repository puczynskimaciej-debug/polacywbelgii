# AI Redaktor i ogłoszenia — uruchomienie lokalne

1. Klucz Gemini Free Tier zapisz w `agent/.dev.vars` jako `GEMINI_API_KEY=...`. Lokalny Pages Worker czyta również ignorowany przez Git plik `.dev.vars` w katalogu głównym. Ustaw tam `GEMINI_API_KEY`, `GEMINI_FREE_TIER_CONFIRMED=1`, `GEMINI_LOCAL_RELAY_URL=http://127.0.0.1:8793` i losowy `GEMINI_LOCAL_RELAY_TOKEN`. Nie zapisuj wartości w dokumentacji ani commitach.
2. `npm run local:d1:setup` stosuje migracje, w tym `agent/migrations/005_chat.sql`, wyłącznie w `.local/wrangler`.
3. `npm run build`, następnie w osobnych terminalach `npm run local:gemini-relay` i `npm run local:pages`. Otwórz `http://localhost:8791/admin/`. Przekaźnik słucha tylko na `127.0.0.1`, wymaga lokalnego tokenu i ogranicza liczbę żądań. Jest potrzebny w środowiskach, gdzie Wrangler nie może bezpośrednio połączyć się z Gemini. Po wdrożeniu Worker bez zmiennych `GEMINI_LOCAL_RELAY_*` używa bezpośredniego połączenia HTTPS.
4. W „AI Redaktorze” pytania otrzymują odpowiedź Gemini i zapisują się w D1. Zlecenia artykułu są zapisywane jako zadania. Można podać adres oficjalnej strony HTTPS lub sam temat. W drugim przypadku Gemini proponuje adres urzędowy bez płatnego wyszukiwania; wykonawca pobiera tę stronę, sprawdza cytat i odrzuca zadanie, jeśli nie może potwierdzić źródła. To nie jest pełna wyszukiwarka internetowa i może nie znaleźć strony dla każdego tematu. Lokalnie uruchom `npm run agent:chat:process-local`, aby wykonać oczekujące zadanie, także po zamknięciu przeglądarki. Wynik trafia do istniejącej kolejki jako `pending_review`; administrator nadal musi zweryfikować i zatwierdzić treść. Docelowy Worker `workers/chat.mjs` może wykonywać tę samą kolejkę przez Cron po osobnym wdrożeniu. Nie jest wdrożony ani aktywowany na produkcji.
5. Automatyczne tłumaczenie reklam korzysta z serwerowego Gemini, D1 limitów i w środowisku publicznym wymaga Cloudflare Turnstile. Przed udostępnieniem publicznie ustaw `TURNSTILE_SITE_KEY` i `TURNSTILE_SECRET_KEY` jako sekret/zmienną Pages; bez nich endpoint publiczny odrzuca tłumaczenie. Lokalnie Turnstile nie jest wymagany. Dane klienta i ręczne poprawki pozostają w formularzu.
6. Testy celowane: `npm run test:ai-chat-ads`, `node --test tests/cloudflare.test.mjs`, `npm run build`, `npm run lint`.

Reklamy bez grafiki wykorzystują wspólny renderer CSS w podglądzie i publicznym widoku. Grafika przypisana do języka jest przechowywana w istniejącym rekordzie wariantu zamówienia, bez osobnej tabeli i bez zmian liczby miejsc ani cennika.
